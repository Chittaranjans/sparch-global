# AI Job Search Platform - Frontend

Modern Next.js frontend with TypeScript and Tailwind CSS for the AI-powered job search platform.

## 🚀 Quick Start

```bash
# Install dependencies
bun install

# Start development server
bun run dev
```

The app will be available at [http://localhost:3001](http://localhost:3001)

## 🎯 Features

- **AI-Powered Job Matching**: Upload resume for intelligent job recommendations
- **Advanced Filters**: Filter by remote/hybrid, experience level, salary, etc.
- **Application Tracking**: Manage applications through entire hiring pipeline
- **Favorites**: Save and manage favorite jobs
- **Interview Prep**: AI-generated interview questions for each position
- **Similar Jobs**: Find related opportunities with similarity scores

## 📦 Tech Stack

- Next.js 16 + TypeScript
- Tailwind CSS 4
- Zustand (State Management)
- Lucide React (Icons)
- Bun Runtime

## 🔧 Environment Setup

Create `.env.local`:
```env
NEXT_PUBLIC_API_URL=http://localhost:3000
```

## 📝 Available Scripts

- `bun run dev` - Start development server (port 3001)
- `bun run build` - Build for production
- `bun run start` - Start production server
- `bun run lint` - Run ESLint
